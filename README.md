# Мои анализы

Личный трекер анализов, показателей и заключений. Статичный сайт, без сервера.
Данные хранятся **только в вашем браузере** (IndexedDB), в репозиторий они не попадают.

## Публикация на GitHub Pages
1. Создайте репозиторий (Public — Pages на бесплатном тарифе работают только так; код публичный, данные — нет).
2. Загрузите файлы, Settings → Pages → Source: `main` / root.
3. Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`.

## Важно
- Не коммитьте файлы резервных копий (`medtracker-backup-*.json`) — в них ваши данные.
- Копию делайте регулярно: Данные → «Скачать копию».
- Референсные значения в каталоге — ориентир, ориентируйтесь на бланк вашей лаборатории.
