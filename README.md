# Мои анализы

Личный медицинский архив: анализы, исследования (УЗИ, МРТ, рентген…), заключения врачей.
Статичный сайт без сервера. Записи и сканы хранятся **только в браузере на вашем устройстве**,
распознавание сканов тоже идёт на устройстве (библиотеки лежат в папке `vendor`).

## Публикация на GitHub Pages
1. Создайте репозиторий (Public — на бесплатном тарифе Pages работают только так; публичен код, не данные).
2. Загрузите все файлы и папку `vendor` целиком (перетащите в «Add file → Upload files»).
3. Settings → Pages → Source: ветка `main`, папка `/ (root)`.
4. Сайт откроется по адресу `https://<логин>.github.io/<репозиторий>/`. На телефоне его можно добавить на главный экран.

## Важно
- Не загружайте в репозиторий резервные копии (`medtracker-backup-*.json`) — в них ваши данные.
- Делайте копию регулярно: Данные → «Скачать копию». Через неё же данные переносятся на другое устройство.
- Распознавание может ошибаться: перед сохранением сверяйте значения со сканом.
- Нормы в справочнике ориентировочные, при распознавании норма берётся из бланка.

## Файлы
`app.js` — интерфейс, `parse.js` — разбор текста сканов, `ocr.js` — распознавание,
`catalog.js` — справочник показателей (можно дополнять), `sw.js` — работа офлайн.
